The Pass worksheet Saving locally…

Paste the webhook URL and sender key from the Pass worksheet marks routine (right-click the routine → copy fields). After that, each yea / nay / change and each note pause will send itself. Marks also stay on this device.

If you skip the webhook, use Download or I'm done, and paste the file into chat. The file backup writes marks.json whenever you change a row.

The Pass

A kitchen island working-memory loop. Projector on the island, a durable card you can hold, a receipt slip for the next small action, a scanner, and Home Assistant for the pings. Nothing here is decided. Write in the margin.

Marks save on this device as you go. With Send setup filled in, each mark also leaves the device so half a sheet cannot vanish with a closed tab.

Offline-capable. Install it if your browser offers that. Your marks live in IndexedDB on this device, and optionally in a folder you pick and in the webhook.
